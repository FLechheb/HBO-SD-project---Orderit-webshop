# Projectnaam

## Beschrijving

Dit project is ontwikkeld in Java en maakt gebruik van een JSON-bestand voor het opslaan/inlezen van gegevens.

## Vereisten

Voor het uitvoeren van de applicatie is het volgende vereist:

- IntelliJ IDEA
- Java JDK 17 (of jouw gebruikte versie)

Controleer de Java-versie met:

java -version

## Project openen

1. Pak het ZIP-bestand uit.
2. Open IntelliJ IDEA.
3. Kies "Open".
4. Selecteer de uitgepakte projectmap.
5. Wacht tot IntelliJ het project heeft geladen.

## Configuratie

Indien IntelliJ vraagt om een JDK te configureren:

1. Open File > Project Structure.
2. Kies Project.
3. Selecteer de juiste Java SDK.

## JSON-bestand

De applicatie maakt gebruik van het volgende JSON-bestand:

vruchtenlijst.json

Dit bestand moet aanwezig blijven op de meegeleverde locatie.

Wanneer het bestand wordt verplaatst, dient het pad in de applicatie te worden aangepast.

## Applicatie starten

1. Open de klasse die de main()-methode bevat.
2. Klik op de groene Run-knop naast de main()-methode.

Of:

Run > Run 'Main'

## Projectstructuur

/src
- Java broncode

/resources
- Configuratiebestanden
- JSON-bestanden

README.md
- Deze handleiding

## Opmerkingen

- Alle broncode is opgenomen in deze oplevering.
- De applicatie is getest binnen IntelliJ IDEA.
- Eventuele toekomstige uitbreidingen kunnen binnen dezelfde projectstructuur worden uitgevoerd.
